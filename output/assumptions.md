# Assumptions Made During Problem Solving

1.  **Source Material:** It is assumed that the user wants the problem-solving methodology described in `solve.md` to be directly adapted and formatted as the final AI prompt. The goal is not to invent a new methodology but to present the existing one clearly as instructions for another AI.
2.  **AI Capabilities:** The target AI for the final prompt is assumed to have the necessary capabilities mentioned (reading/writing files, understanding task breakdown) as stated in `problem_description.md`.
